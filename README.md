# Digital Heroes

A full-stack golf performance, charity, and monthly draw platform.

## Project Structure

- `frontend` - Web application
- `backend` - Spring Boot REST API
- `database` - Database scripts and documentation
- `docs` - Project documentation

## Core Features

- User registration and login
- Subscription management
- Golf score management
- Charity selection
- Monthly prize draws
- Winner verification
- User dashboard
- Admin dashboard
